# 业界同类软件对标分析

> 对标对象：Typora、Obsidian、MarkText、VS Code（+ Joplin / Zettlr 参考）
> 用途：为 MdEv 的功能规划提供依据。每轮迭代后请更新「MdEv 现状」列。

---

## 一、业界产品功能模块与核心技术

### Typora — 极致写作体验

| 维度 | 内容 |
|---|---|
| 定位 | 沉浸式所见即所得 Markdown 写作 |
| 核心技术 | 自研实时渲染引擎（源码与渲染合一，无分栏）；Electron 壳 |
| 功能模块 | WYSIWYG 编辑、大纲面板、文件树、全文搜索、字数统计、主题系统（CSS 定制）、图片「复制到 assets 并转相对路径」、导出 PDF/HTML/Word/图像/EPUB、数学公式、图表（Mermaid）、表格可视化编辑 |
| 体验亮点 | 选中文本粘贴 URL 自动变链接；表格源码自动对齐；`:emoji:` 短代码；打字机/专注模式；粘贴图片自动存入 `./assets` |
| 短板 | 闭源收费；无插件生态；无双链 |

### Obsidian — 知识管理

| 维度 | 内容 |
|---|---|
| 定位 | 本地优先的双链知识库（Vault 概念） |
| 核心技术 | CodeMirror 6 编辑器；Vault = 本地文件夹；插件系统（社区 1000+ 插件）；本地 JSON 缓存索引（反链/大纲/图谱） |
| 功能模块 | 双链 `[[]]` + 反向链接面板、关系图谱、标签系统、每日笔记、模板、命令面板、快速切换器、本地文件历史（File Recovery，快照自动保存）、大纲、搜索（支持操作符） |
| 体验亮点 | `Ctrl+P` 命令面板 + `Ctrl+O` 快速切换双入口；状态栏字数点击看详情；标签页固定（pin）； vault 级全文检索毫秒级响应（索引） |
| 短板 | 学习曲线陡；渲染引擎（非 WYSIWYG）|

### MarkText — 开源 Typora 替代

| 维度 | 内容 |
|---|---|
| 定位 | 开源实时预览 Markdown 编辑器 |
| 核心技术 | Electron + Vue + 自研 Muya 编辑器（内容块渲染） |
| 功能模块 | 与 Typora 类似的所见即所得、源码模式切换、图片工具（上传/复制 assets）、文件树、标签页、主题 |
| 体验亮点 | 拖拽文件/图片入窗口；选区浮动格式工具条 |
| 短板 | 维护不活跃；大文档性能一般 |

### VS Code — 通用编辑器基准

| 维度 | 内容 |
|---|---|
| 定位 | 通用代码/文本编辑器（Markdown 是重要场景之一） |
| 核心技术 | 自研 Monaco（CodeMirror 前身思想）、LSP、扩展 API、文本模型统一（一切皆命令） |
| 功能模块 | 命令面板（`Ctrl+Shift+P`）、快速打开（`Ctrl+P`）、多标签（pin/preview 模式）、文件历史（Timeline，本地+Git）、本地历史快照、Markdown 预览、表格格式化（扩展）、拖拽打开 |
| 体验亮点 | 所有功能都可从命令面板触达；`Shift+Alt+F` 格式化；拖文件到窗口即打开；固定标签防误关；设置项全量持久化 |
| 短板 | Markdown 专项体验（公式/图表/导出）需装扩展 |

### Joplin / Zettlr（参考）

- **Joplin**：笔记管理 + 同步（端到端加密）、插件市场；编辑器体验一般。
- **Zettlr**：学术写作（引用/CSL、Pandoc 导出）；Zettelkasten 工作流。

## 二、核心技术趋势总结

1. **编辑器内核趋同于 CodeMirror 6**（Obsidian 已迁移）——MdEv 选型正确。
2. **「一切皆命令」架构**：命令面板是功能发现的主入口，菜单只是子集。
3. **本地优先 + 快照容灾**：本地历史/文件恢复是桌面编辑器的标配安全感。
4. **图片资产化管理**：粘贴/拖入 → 复制到 assets 目录 → 相对路径引用，可配置目录。
5. **标签页管理**：pin 固定、拖拽排序、防误关。
6. **双链/图谱**是知识管理方向的分水岭，纯写作工具可不做。

### 后续候选（按价值排序）

1. **双链笔记 `[[wiki link]]`**（Obsidian 核心吸引力）：需链接索引 + 反链面板，工程量大
2. **所见即所得模式**（Typora 核心）：架构级改动，建议评估 Milkdown / TipTap 或 CM6 官方 WYSIWYG 方案
3. **PDF 导出页眉页脚**（printToPDF 原生支持 headerTemplate/footerTemplate）
4. **Mermaid 图表导出修复**（导出 HTML/PDF 中图表需内联渲染）
5. **大文件性能**：预览 `content-visibility` 分段渲染、Mermaid 懒加载
6. **快捷键自定义**：设置项 + keymap 重映射
7. **标签预览模式**（VS Code 斜体预览标签：单击打开、双击固定）
8. **文件历史加入 Git 集成**（Timeline 显示 Git 提交）
